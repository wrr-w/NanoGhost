NanoGhost · 架构（渠道 = 完整适配器）
分层：外部世界（飞书） ── 渠道适配器 Channel（含底层）── 内核（平台无关）。
Channel 对上层只露「接口」，两侧都做归一：入站原始事件 → 通用对象；出站通用 blocks → 平台消息。

一句话 · 你的理解（修正后）
✅ Channel 含底层（WS / API / 解析 / 会话，全在里面）—— 对外只露一个「能力接口面」。
✅ 只给上层展示自己的能力接口（capabilities + 出站 + 入站）—— 对的。
⚠️ 补一点：归一化是双向的 —— 不只是「把消息归一接进上层」，也负责「把上层的 blocks 归一成平台消息发出去」。
→ 所以 Channel = 双向翻译官 + 完整适配器：入站 原始 → 通用，出站 通用 → 原始；内核永远只见通用。
